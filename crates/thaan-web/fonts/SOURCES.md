# Fonts for the browser demo

The browser has no system fonts GPUI can read, so the demo embeds these. Both are under
the SIL Open Font License 1.1 (licence texts beside them) and shipped unchanged.

| Files | Source | Version |
| --- | --- | --- |
| `Inter-Regular.ttf`, `Inter-Medium.ttf`, `Inter-SemiBold.ttf` | [rsms/inter](https://github.com/rsms/inter) release `Inter-4.1.zip`, `extras/ttf/` | 4.1 |
| `JetBrainsMono-Regular.ttf`, `JetBrainsMono-Medium.ttf` | [JetBrains/JetBrainsMono](https://github.com/JetBrains/JetBrainsMono) release `JetBrainsMono-2.304.zip`, `fonts/ttf/` | 2.304 |

Fetched on 2026-11-26. The desktop app uses the system fonts and does not ship these.
